# Whitemark Preview

Адаптивная вёрстка страницы контактов для проекта **Whitemark**.

## О проекте

Проект выполнен по готовому макету с использованием HTML и SCSS.

Основное внимание уделено:

- адаптивной вёрстке;
- семантической структуре HTML;
- организации стилей по блокам;
- работе с SVG-спрайтом;
- подключению локальных шрифтов;
- корректному отображению на разных разрешениях экрана.

## Технологии

- HTML5
- SCSS / CSS
- SVG
- БЭМ
- Git

## Структура проекта

```text
preload-prod/
├── contacts.html
├── css/
├── fonts/
├── images/
└── scss/
    ├── blocks/
    ├── global/
    └── style.scss
```

## Особенности

- адаптивная вёрстка;
- кастомные шрифты TT Norms Pro;
- SVG-спрайт с логотипами компаний;
- SCSS с разделением на глобальные стили и блоки;
- оптимизированные изображения.
